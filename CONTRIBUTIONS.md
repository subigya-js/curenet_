# CureNet contributions

CureNet originated as a collaborative final-year computer engineering project.
Work was divided by module and integrated by the team.

## Primary portfolio contribution

- Developed the React frontend and user-facing workflows.
- Developed the lung CT classification module using MobileNetV2 transfer learning.
- Integrated Grad-CAM attention visualization for lung-model predictions.
- Contributed substantially to the symptom-based information-retrieval module.
- Helped integrate the frontend with the backend and ML inference services.

## Other team-led contributions

- The brain-stroke CT classification pipeline was led by another team member.
- The Node.js/Express APIs and MySQL integration in the original HMS prototype
  were led by another team member.

## Collaborative work

- Chatbot and retrieval design
- Overall system design and integration
- Testing and demonstration
- Original final-year report

This document describes module ownership without implying that collaborative
components were produced by one person.
